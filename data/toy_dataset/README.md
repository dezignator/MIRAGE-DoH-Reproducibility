# Toy dataset

**This directory ships with empty CSVs (header row only).** The actual data
is generated by `data/make_toy_dataset.py`. See `data/README_data.md §4` for
the full real-vs-synthetic distinction.

## Why the CSVs are empty in the repository

The two CSVs contain the correct 47-column schema but zero data rows.
Shipping the full 2 000 rows would add ~200 KB to the repository for no
benefit, since the generator reproduces them deterministically from
`seed=42`. Shipping a *smaller* pre-generated dataset would confuse the
reviewer about which mode produced it.

The empty files serve one purpose: making the schema visible in the
repository tree. Open either CSV in GitHub's web view and you will see the
47 column names.

## Two ways to populate the CSVs

### Synthetic (default, instant)

```bash
python data/make_toy_dataset.py --synthetic --seed 42
